# 《漂流小镇》完整游戏设计方案

> 文档版本 1.0 · 2026-11-22
> 定位：水上漂流生存建造 → 城镇经营 → 潜水采集与店铺管理
> 参考：《Flotsam》的浮动聚落建造、《潜水员戴夫》的潜水采集与寿司店经营
> 关联文档：[README.md](./README.md)（当前可玩实现）、[PROGRESS.md](./PROGRESS.md)（开发进度）

## 一、一句话定位

> **在无尽漂浮的海洋世界里，你靠打捞垃圾从一个木筏开始，把废墟变成可以自给自足的水上城镇，
> 招募流浪者开辟商店，最后潜入水下世界，把海的馈赠变成桌上的一餐。**

**核心体验差异**：不是「海洋版牧场物语」，而是**「回收 → 建造 → 经营 → 深潜」四层递进的水上共生体**。
玩家每一层都在用同一套资源语言（垃圾/材料/食材）解决新问题。

---

## 二、世界观

### 背景

**大潮之后（The Great Tide）**——一场持续四十年的海平面上升让大陆沉没。
幸存者没有被困境压垮，而是抓住一切漂浮物，用缆绳把它们捆在一起，形成**漂流聚落（Drift Town）**。

海洋不再只是威胁，而是**唯一的资源和唯一的土地**：垃圾是建材，鱼是粮食，沉城的残骸是宝库。
浮岛之间靠**洋流与季风**缓慢移动，因此城镇既是家，也是一艘永远在航行的船。

### 世界规则（服务于玩法的三条设定）

1. **塑料永存**——合成垃圾不会降解，成了最可靠的建材。这解释了「为什么捡垃圾是正当玩法」。
2. **潮汐窗口**——海面每隔一段时间进入平潮期，是潜水的唯一机会。这是潜水玩法的入场券。
3. **流浪者顺流而来**——失散的幸存者会随浮木漂来，他们带来技能、配方和故事。这是 NPC 招募的合法性。

### 基调

明亮、乐观、带一点狼狈的可爱。不是末日悲歌，而是**「大家都挺惨的，但我们活得挺开心」**。
参考视觉：低多边形 + 高饱和 + 阳光穿透水面。

## 三、核心循环

### 3.1 主循环（三层嵌套）

```
┌─ 微循环 (30–90 秒) ────────────────────────────────────┐
│  驾筏打捞 → 拆解成材料 → 材料够了 → 造建筑/造装备          │
│  反馈：即时音效 + 建筑生长动画 + 数值弹字                  │
└──────────────────────┬───────────────────────────────┘
                       ↓ 累积
┌─ 中循环 (10–25 分钟) ─────────────────────────────────┐
│  攒材料 → 解锁图纸 → 扩建浮岛 → 招募流浪者              │
│  → 解锁商铺 → 收入提升 → 买更好的装备/更大的筏           │
│  反馈：新建筑、新 NPC、新可去区域                        │
└──────────────────────┬───────────────────────────────┘
                       ↓ 累积
┌─ 大循环 (数小时) ─────────────────────────────────────┐
│  探索新海域 → 发现沉城 → 解锁潜水装备                    │
│  → 采集稀有食材 → 寿司店品类扩张 → 声望 → 解锁更远海域    │
│  反馈：地图扩展、生态揭示、世界叙事                      │
└─────────────────────────────────────────────────────┘
```

### 3.2 单次潜水的子循环（《潜水员戴夫》式）

```
下水（限时/限量氧气）→ 采集（鱼/贝/海藻/沉城文物）
  → 氧气告急抉择：继续贪 or 上浮保命
  → 回店 → 处理食材（分切/烹饪）→ 上菜单定价
  → 日营业 → 收入 + 口碑 → 升级装备/扩展菜单
```

**关键压力**：氧气是稀缺资源，采集是**主动承担风险**，不是无脑捡。
**关键回报**：稀有食材能卖出高价，但只有活着回来才算。

## 四、设计支柱（5 条）

### 支柱 1 · 垃圾即资源（Waste is Wealth）

**主张**：所有可收集物都能进入生产链，没有「纯垃圾」。
**玩家感受**：「我看到的每一块漂浮物都有用」。
**设计约束**：
- 禁止设计「只能卖钱」的掉落物
- 每种垃圾必须对应 ≥1 条材料支线
- 视觉上让可收集物有明确光晕与色彩编码

**验证**：新手前 3 分钟内，玩家应能说出至少 3 种垃圾的用途。

---

### 支柱 2 · 浮岛是活的（The Island Breathes）

**主张**：城镇不是静态背景板，它会生长、会拥挤、会需要管理。
**玩家感受**：「这是我自己长出来的地方」。
**设计约束**：
- 每座建筑改变浮岛外形或天际线（可见成长）
- 建筑有位置约束（水域/承重/通道），不是随便贴
- 居民有需求（水、食物、床位），不满足会离开

**验证**：玩家会主动截图自己的小镇。

---

### 支柱 3 · 每次下潜都有代价（Dive Has a Price）

**主张**：潜水是高回报高风险，氧气是硬约束。
**玩家感受**：「再抓一条就上浮……不，还能再撑一下」。
**设计约束**：
- 氧气条必须巨大且醒目
- 深水区回报更高但危险更大（鲨鱼/水压）
- 失败惩罚是**损失本次收获**，不是永久死亡（保持乐观基调）

**验证**：玩家会在氧气 20% 时产生明显犹豫。

---

### 支柱 4 · 人让世界温暖（People Make It Warm）

**主张**：NPC 不是功能按钮，是带故事和性格的合作者。
**玩家感受**：「我想知道这家伙以前干嘛的」。
**设计约束**：
- 每个流浪者有小传、特长、喜好
- 招募需要条件（不是纯金钱）
- NPC 会主动触发事件（求助、提议、矛盾）

**验证**：玩家能记住至少 2 个 NPC 的名字和外号。

---

### 支柱 5 · 两层世界互相喂养（Surface Feeds Depths）

**主张**：海面与水下不是两个游戏，是同一经济体的上下游。
**玩家感受**：「我在上面攒的装备，让我在下面走得更远；我在下面抓的鱼，让上面的人过得更好」。
**设计约束**：
- 潜水装备必须由海面材料制造
- 食材必须由寿司店消化
- 两条线都能独立玩，但合起来才有指数收益

**验证**：玩家会主动规划「先攒材料买氧气瓶」。

## 五、MDA 分析

### 5.1 机制（Mechanics）

| 系统 | 机制要点 |
| --- | --- |
| 打捞 | 靠近判定 + 磁吸范围；洋流使物件缓慢漂移 |
| 材料 | 木 / 塑 / 铁 三线；垃圾拆解产出 |
| 建造 | 材料门槛 + 位置约束 + 建造时间 |
| 生存 | 水壶（口渴）、饥饿、居民需求 |
| 战斗躲避 | 鲨鱼扑咬状态机（巡游→预警→扑咬→硬直） |
| 招募 | 流浪者漂流事件 + 招募条件判定 |
| 潜水 | 氧气条 + 深度限制 + 采集判定 + 上浮路径 |
| 经营 | 菜单定价 + 库存消耗 + 日结算 |
| 进度 | 图纸解锁、技能树、区域解锁 |

### 5.2 动态（Dynamics）

| 涌现行为 | 说明 |
| --- | --- |
| **风险偏好分化** | 保守玩家浅水稳收，激进玩家深水豪赌，形成不同节奏 |
| **资源瓶颈转移** | 早期缺木，中期缺铁，后期缺稀有食材——逼玩家换策略 |
| **浮岛拥挤压力** | 建筑多了会互相阻碍，玩家被迫规划空间（自发的解谜） |
| **NPC 组合效应** | 不同特长 NPC 搭配产生不同生产效率，玩家自行发现 |
| **菜单博弈** | 定价高收益高但客流低，玩家会尝试调优 |
| **贪心惩罚曲线** | 氧气机制天然制造「最后一秒」的戏剧性 |

### 5.3 体验（Aesthetics）

按 MDA 的 8 类美学：

| 美学 | 本作对应 |
| --- | --- |
| **Sensation（感官）** | 阳光穿透水面、木筏随浪起伏、潜水时的静谧水声 |
| **Fantasy（幻想）** | 做一个海上流浪者，把废墟变成家 |
| **Narrative（叙事）** | 每个 NPC 的过往、沉没大陆的秘密 |
| **Challenge（挑战）** | 氧气管理、鲨鱼躲避、材料规划 |
| **Fellowship（社交）** | 与 NPC 的关系、居民对玩家的依赖 |
| **Discovery（发现）** | 探索新海域、发现新物种、解锁新配方 |
| **Expression（表达）** | 自由布局浮岛、自定义菜单、命名小镇 |
| **Submission（沉浸）** | 打捞的重复性动作本身带有冥想感 |

**主导美学**：Fantasy（幻想）+ Discovery（发现）
**辅助美学**：Sensation（感官）+ Expression（表达）

> **设计警示**：Challenge 不应成为主导。这是一款**舒缓向**游戏，
> 压力用来制造节奏对比，不用来制造挫败。

## 六、关键系统设计

### 6.1 资源与海洋数据库（Ocean Database）

#### 数据表结构

```
资源 Resource
├─ id, name, icon, category (material|food|artifact|tool)
├─ tier (1-4)                    # 稀有度，决定刷新海域
├─ source (surface|dive|npc)
├─ yield {}                      # 拆解产出：{wood:2, plastic:1}
└─ unlockCondition               # 首次发现触发图鉴条目
```

**四层稀有度与海域绑定**：

| Tier | 名称 | 出现海域 | 代表物 |
| --- | --- | --- | --- |
| 1 | 近岸漂浮物 | 起始海域 | 塑料瓶、易拉罐、木箱 |
| 2 | 洋流带垃圾 | 中距离 | 轮胎、渔网、木桶 |
| 3 | 沉城残骸 | 需潜水 | 金属构件、陶瓷、文物 |
| 4 | 深渊生物 | 深水区 | 稀有鱼类、深海藻 |

#### 海洋数据库（图鉴）

玩家每首次获得一种资源，解锁图鉴条目：

- **视觉**：3D 模型可旋转查看
- **信息**：名称、稀有度、产地、拆解产出、用途链
- **故事碎片**：一句世界观描述（叙事载体）
- **收集进度**：`已解锁 37/120`，分类统计

**设计要点**：图鉴是**软性目标**，不做强制收集，但完成度给实质奖励（配方/装饰）。

---

### 6.2 玩家成长与技能解锁

#### 三条成长轴（并行，不互斥）

| 轴 | 载体 | 提升方式 |
| --- | --- | --- |
| **规模** | 浮岛面积、建筑数 | 消耗材料扩建 |
| **能力** | 技能树（3 分支） | 使用对应行为积累经验 |
| **声望** | 城镇等级 | 完成 NPC 委托、营业表现 |

#### 技能树（用行为解锁，非纯经验值）

```
采集分支                    建造分支                    经营分支
├ 打捞范围+               ├ 建造速度+               ├ 菜品售价+
├ 磁吸强度+               ├ 材料损耗-               ├ 客流+
├ 潜水氧气上限+           ├ 建筑耐久+               ├ 菜单位+
└ 深水抗压               └ 浮岛承重+               └ 员工效率+
```

**解锁机制**：每个分支的经验只由对应行为产生——
- 打捞 100 件 → 采集分支升级
- 建造 10 座 → 建造分支升级
- 营业 5 天 → 经营分支升级

**设计意图**：玩家玩什么就擅长什么，形成**自然分化**而非强制选择。

#### 关键装备解锁链

```
徒手打捞
  └→ 捞网（木2）              → 打捞范围 +50%
      └→ 钩爪（木3 铁2）       → 可拉取远处物件
          └→ 浮潜镜（塑4 铁1）  → 解锁浅水采集
              └→ 氧气瓶（铁5 木3）→ 潜水时长 60s→120s
                  └→ 潜水服（铁8 塑6）→ 可下潜 Tier 3
                      └→ 深潜器（全部 Tier 3 材料）→ 解锁 Tier 4
```

### 6.3 管理后台（Admin / Live-Ops Panel）

用于运营配置，不面向玩家。

#### 模块一 · 玩家进度

| 字段 | 用途 |
| --- | --- |
| playerId / 昵称 / 创建时间 | 基础信息 |
| 城镇等级 / 建筑数 / 图鉴完成度 | 进度快照 |
| 当前海域 / 最深层数 | 位置 |
| 资源存量（木/塑/铁/食材） | 经济监控 |
| 最近 7 日登录 / 单局时长 | 留存分析 |
| 卡点标记 | 自动识别「停留超过 20 分钟未推进」 |

**运营动作**：查看个体、发放补偿、重置进度、标记测试账号。

#### 模块二 · 数据库条目

CRUD 全资源表：

```
[新建条目]
  名称 / 图标 / 分类 / 稀有度
  产地：海面 | 潜水 | NPC
  拆解产出：可挂多个 {资源, 数量}
  刷新权重：控制该物件出现频率
  解锁条件：首次获得 / 完成前置任务
  图鉴文案：一句话世界观
[批量操作] 导入 CSV / 导出 / 按稀有度批量改权重
```

**关键能力**：**不做发版就能调平衡**——改刷新权重和产出量立即生效。

#### 模块三 · 配方与建筑

```
建筑配置
├ 名称 / 模型 / 占地格数
├ 造价 {wood, plastic, metal}
├ 建造时长
├ 前置条件（建筑 A 已建成 / 技能 B 已解锁）
├ 产出（居住位 / 生产速率 / 增益）
└ 位置约束（水域/陆地/岸边）

配方配置（含寿司店）
├ 成品 / 所需食材与数量
├ 制作时长
├ 基础售价 / 建议定价区间
├ 解锁条件
└ 口碑加成
```

#### 模块四 · NPC 与事件

```
NPC 配置
├ 姓名 / 头像 / 小传
├ 特长（打捞/建造/烹饪/潜水）
├ 招募条件 {声望, 建筑, 物资}
├ 出现时机（第 N 天 / 建成某建筑后）
└ 好感度事件链

事件配置
├ 触发条件（时间/进度/随机权重）
├ 事件类型：求助 | 交易 | 冲突 | 剧情
├ 选项与结果（给资源/给配方/增减好感）
└ 冷却时间
```

## 七、解锁链（核心命题）

> 用户明确要求的顺序，本节给出**可执行的依赖关系**。

### 阶段总览

```
阶段 0  求生            阶段 1  立足            阶段 2  成镇
木筏 + 徒手打捞    →    庇护所 + 生存装备  →   城镇中心 + 商铺
                                                      ↓
阶段 4  深海经营        阶段 3  人烟
潜水 + 寿司店     ←    流浪 NPC 招募
```

### 阶段 0 · 求生（0–10 分钟）

**目标**：活下来，理解基础循环

| 要做 | 条件 |
| --- | --- |
| 打捞垃圾 | 徒手，范围小 |
| 建造 **工作台** | 木×4 |
| 观察口渴/饥饿 | 无（此时压力温和） |

**解锁**：工作台建成 → 打开建造菜单

---

### 阶段 1 · 立足（10–40 分钟）

**目标**：从「漂着」变成「有家」

**1.1 建造庇护所（关键节点）**

```
工作台
  └→ 庇护所（木×8 塑×2）
       效果：解锁床位、存档点、可过夜
       解锁：生存装备图纸
```

**1.2 必要生存装备（顺序有依赖）**

| 装备 | 造价 | 效果 | 前置 |
| --- | --- | --- | --- |
| 集雨器 | 木×3 塑×2 | 缓解口渴 | 庇护所 |
| 鱼篓 | 木×4 | 小幅食物 | 庇护所 |
| 捞网 | 木×3 | 打捞范围 +50% | 庇护所 |
| 净水器 | 木×4 铁×2 | 稳定供水 | 集雨器 + 工作台 |

> ⚠️ **设计约束**：生存装备全部**先于**城镇解锁，
> 否则玩家会在「还没稳定求生」时被城镇管理分散注意力。

**完成标志**：口渴与饥饿可自持（可持续 5 分钟不采集也不死）→ **解锁城镇**

---

### 阶段 2 · 成镇（40 分钟–3 小时）

**目标**：从营地变成社会

```
庇护所 + 生存自持
  └→ 城镇中心（木×15 塑×8 铁×5）  ← 关键里程碑
       效果：解锁浮岛扩建、居民上限、声望系统
       │
       ├→ 民居（木×6）        → 居民 +2
       ├→ 码头（木×10 铁×3）  → 解锁更大船只、可去更远海域
       └→ 市场（木×12 铁×4）  → 解锁交易，可买卖资源
```

**城镇建立的判定**：城镇中心建成 + 有 ≥2 座民居 + ≥3 名居民

**解锁**：城镇正常运行 → **流浪 NPC 开始出现**

---

### 阶段 3 · 人烟（3–6 小时）

**目标**：把城镇变成有人的地方

**3.1 流浪 NPC 招募机制**

流浪者随浮木漂来，触发条件：

| 条件 | 说明 |
| --- | --- |
| 城镇已建立 | 硬前置 |
| 声望 ≥ 阈值 | 城镇越好，来的人越靠谱 |
| 有招募设施 | 需要先建**旅店**（木×14 塑×6） |
| 时间窗口 | 每 1–2 个游戏日出现 1 位 |

**招募流程**：
```
漂流者出现（可视：浮木上的小人）
  → 靠近对话 → 了解需求（可能是物资/任务/技能验证）
      → 完成需求 → 招募成功
          → 分配岗位（打捞/建造/烹饪/潜水/看店）
```

**NPC 类型（首批 6 位）**：

| 名字 | 特长 | 招募条件 | 解锁内容 |
| --- | --- | --- | --- |
| 老陈 | 打捞 | 交付木×20 | 自动打捞（离线收益） |
| 阿海 | 潜水 | 有浮潜镜 | 潜水氧气 +20s |
| 小满 | 烹饪 | 有市场 | 解锁寿司店图纸 |
| 铁匠波 | 建造 | 有铁×15 | 建筑耐久+，配方折扣 |
| 莉莉 | 经营 | 声望 3 级 | 售价 +10% |
| 无名老人 | 剧情 | 城镇等级 5 | 揭示沉城线索 → 解锁 Tier 3 海域 |

**关键设计**：**小满**是解锁寿司店的关键 NPC——让「人」推动玩法解锁，
而不是纯靠数值门槛。

---

### 阶段 4 · 深海经营（6 小时+）

**目标**：开启第二套玩法（《潜水员戴夫》融合层）

**4.1 解锁条件（硬链条）**

```
招募小满
  └→ 获得「寿司店图纸」
      └→ 寿司店建成（木×18 塑×10 铁×12 + 稀有材料）
          └→ ✅ 解锁潜水采集
          └→ ✅ 解锁食材经营
          └→ ✅ 解锁店铺管理
```

> ⚠️ **这是用户明确要求的核心链路**：
> **寿司店建成 → 解锁潜水 + 食材经营 + 店铺管理**

**4.2 潜水采集（新增玩法）**

| 要素 | 设计 |
| --- | --- |
| 氧气 | 初始 60s，装备可提升；耗尽则强制上浮并损失本次收获 |
| 深度层 | 浅水（安全）/ 中层（有鲨鱼）/ 深水（Tier 3 食材） |
| 采集 | 靠近采集，部分生物会逃跑（需要潜行） |
| 危险 | 鲨鱼、水母、暗流 |
| 收获 | 鱼类、贝类、海藻、沉城文物 |

**4.3 食材经营**

```
潜水收获 → 食材库存
  → 寿司店菜单（选 3–6 道菜上架）
      → 定价（高利润 vs 客流）
          → 日营业结算 → 收入 + 口碑
```

**菜单配置示例**：

| 菜品 | 食材 | 成本 | 建议售价 |
| --- | --- | --- | --- |
| 海藻卷 | 海藻×2 + 米 | 8 | 15 |
| 银鳞握寿司 | 银鳞鱼×1 + 米 | 12 | 28 |
| 深海蟹肉军舰 | 深海蟹×1 + 海藻×1 | 30 | 75 |

**4.4 店铺管理**

- **员工**：可雇 NPC 做服务员/厨师，影响翻台速度
- **菜单位**：初期 3 格，扩建后 6 格
- **口碑**：影响客流量与食材采购价
- **日结算**：收入 - 食材成本 - 员工工资 = 净利

**4.5 闭环**

```
寿司店赚钱 → 买更好潜水装备 → 潜更深 → 稀有食材
  → 高价菜品 → 更多钱 → 扩建浮岛 → 吸引更好 NPC
```

## 九、主要风险

### 风险矩阵

| # | 风险 | 概率 | 影响 | 缓解措施 |
| --- | --- | --- | --- | --- |
| R1 | **四层玩法缝合失败**，每层都浅 | 高 | 致命 | MVP 只做前两层，验证手感后再加潜水；潜水作为独立可玩模块先做原型 |
| R2 | **解锁链过长**，玩家 2 小时才能见到潜水 | 高 | 高 | 缩短前期：庇护所 10 分钟内可建；提供「快速体验」入口直接跳阶段 3 |
| R3 | 潜水与海面**经济失衡**（潜水收益碾压） | 中 | 高 | 数值建模：按分钟收益对齐两条线；潜水有硬成本（装备损耗、氧气） |
| R4 | NPC 招募变成**纯数值门槛**，不好玩 | 中 | 中 | 每位 NPC 至少 1 个「人格化」任务，不是交材料 |
| R5 | 浮岛**布局自由度**引发卡关（建筑堵死） | 中 | 中 | 提供移动/拆除功能；关键通道做占地保护 |
| R6 | 管理后台**过早复杂化**，拖慢迭代 | 中 | 中 | MVP 阶段只做「资源刷新权重」一项可调，其余用改配置文件 |
| R7 | 手机端**潜水操作**困难（3D 上下移动） | 高 | 高 | 潜水改**2.5D 横版/俯视**，只做平面移动 + 深度分层 |
| R8 | 内容量不足，3 小时后无目标 | 中 | 高 | 图鉴 120 条 + 技能树 + 声望等级提供中期目标 |
| R9 | 微信小游戏**包体超限**（4MB） | 中 | 中 | 模型程序化生成（当前已如此）；贴图用 Canvas 生成；分包加载 |
| R10 | 单人开发**内容生产瓶颈** | 高 | 高 | 优先程序化生成；NPC 用模板+参数变体；避免手绘大量美术 |

### 关键决策建议

**建议 1：先做「垂直到顶」而非「横向铺开」**

用 MVP 的一层玩法 + 潜水原型各做一个**可玩 10 分钟的垂直切片**，
先验证「打捞爽不爽」和「潜水紧张不紧张」，再决定投入比例。

**建议 2：潜水必须在手机上有好的操作方案**

3D 自由泳在触屏上体验很差。强烈建议：
- 潜水采用**俯视平面移动**（与海面一致），深度用「层」切换
- 氧气条占据屏幕顶部（压力可见）
- 采集用「靠近 + 按钮」

**建议 3：解锁链可以更紧凑**

用户要求的链条完整合理，但 2 小时才能见到寿司店偏长。
建议：
- 庇护所 → 城镇 压缩到 20 分钟
- 城镇 → 首个 NPC 压缩到 10 分钟
- NPC → 寿司店 保留 30 分钟（这部分内容密度高，慢一点没关系）
