========================================================
潜水玩法原型 (prototype/dive/)
========================================================
独立可玩, 108KB 单文件纯 Canvas 2D, 双击即开。
用途: 验证设计文档最高危风险 R7「手机端 3D 自由泳操作困难」。

方案: 俯视平面移动 + 三层深度 + 氧气压力 + 回程安全线

R7 验证结论 (量化):
- 双通道同时操作帧占比: 俯视 0% vs free3d 对照 92%  <- 决定性差异
- 微深度对准失败/局: 0 vs 125.3
- 平均带回价值: 209.8 vs 164.4 (+27%)
- 风险-回报曲线单峰: 保守164 < 平衡212 > 贪婪179 (中间最优)
- 诚实边界: 操作性风险被证伪, 但「好玩」INSUFFICIENT (无真人数据)

对设计文档的 6 条回改建议, 最重要的两条:
1. 深度分层会退化成「三张一样的图」, 每层须有独有空间动词
2. 氧气压力的可见性 > 大小, 需要「回程安全线」

数据表与后台 (data/ + admin/)
========================================================
data/: 4 张严格 JSON 表
- resources.json 29 条 (海面8/潜水16/NPC1/制作4)
- buildings.json 18 条 (12 已实现 + 6 设计)

admin/index.html: 105KB 自包含配置面板
- 玩家进度(8位模拟/卡点检测) / 数据库条目(可改权重) / 配方建筑(依赖链高亮) / NPC事件
- 导出 JSON + localStorage 持久化

关键设计:
- spawnWeight 权重和 = 12, 恰为 game.js Math.random()*12 区间宽度
  -> 后台改数字 = 直接改实际出现比例, 不发版就能调平衡
- usedBy 由其它表派生而非手写 (手写版被校验抓出 8 处编造引用)
- 新增 materials 中间层: 垃圾 -> 材料 -> 建筑 两跳关系
