# 漂流小镇 (Drift Town)

一个 Flotsam 风格的 3D 体素海上生存建造小游戏。驾驶木筏在海上打捞漂浮垃圾，
把垃圾换成建筑材料，在木筏上盖起一座漂流小镇，同时躲开鲨鱼、照看水壶。

- **引擎**：three.js（体素 / 低多边形），纯前端单文件
- **平台**：Web（浏览器）、微信小游戏
- **游戏时长**：240 秒（生存层需要时间，85 秒跑不完阶段 0-1）
- **当前版本**：**1.4.0**

## 当前实现的完整链路

```
打捞海上垃圾 → 拆成木/塑/铁 → 造工作台 → 造庇护所
    → 造 4 件生存装备（集雨器/鱼篓/捞网/净水器）
        → 水与食能自持 60 秒 → 解锁城镇
            → 生存自持后 HUD 出现「潜」按钮
                → 潜水采集 → 收获转食物与分数
```

### v1.4.0 的两个关键能力

**1. 数据表驱动（改权重不发包）**

游戏从 `data/resources.json` 与 `data/buildings.json` 读取数值。
7 种垃圾的 `spawnWeight` 之和恒为 **12**（等于原 `Math.random()*12` 的区间宽度），
所以后台改权重 = 直接改实际出现比例：

```js
// 运行期热更新（Web 与微信均可）
GameData.init({ resources: tunedResources });
```

**2. 潜水玩法（已接入主游戏）**

`prototype/dive/dive-canvas.js` 是零 DOM 的 Canvas 模块，
生存自持后点击「潜」按钮进入，整屏交给它绘制与处理输入。
氧气 60 秒、三层深度、红色回程安全线、失败损失全部收获。

## 1. 玩法

### 核心循环

```
驾木筏靠近漂浮垃圾 → 打捞 → 拆成材料（木 / 塑 / 铁）
                                ↓
                        材料够了 → 造建筑 → 获得增益
                                ↓
                        造齐 6 座 → 小镇落成（胜利）
```

### 操作

| 操作 | 键盘 | 触屏 |
| --- | --- | --- |
| 移动 | 方向键 / WASD | 拖动屏幕（虚拟摇杆） |
| 冲刺 | 空格 / J | 右下角 ⚡ 按钮 |
| 选图纸 | ← → 选择，Enter 确认 | 点击卡片 |
| 暂停 / 静音 | P / M | — |

### 系统

**1. 材料经济**
垃圾分 7 种，各有材料产出与分值：

| 垃圾 | 分值 | 产出 |
| --- | --- | --- |
| 塑料瓶 | 1 | 塑×1 |
| 易拉罐 | 1 | 铁×1 |
| 橡皮鸭 | 1 | 塑×1 |
| 木箱 | 2 | 木×2 |
| 木桶 | 2 | 木×1 铁×1 |
| 轮胎 | 2 | 塑×1 铁×1 |
| 渔网 | 3 | 木×1 塑×2 |

**2. 六座建筑**（材料够时弹出二选一图纸）

| 建筑 | 造价（木/塑/铁） | 居民 | 增益 |
| --- | --- | --- | --- |
| 小屋 | 4/0/0 | +1 | 心上限 +1 |
| 水塔 | 3/3/0 | +1 | 水壶 +25 |
| 温室 | 2/4/0 | +1 | 拾取范围增加 |
| 灯塔 | 3/2/3 | +0 | 护盾时间更长 |
| 市集 | 4/3/3 | +2 | 单件收益 +1 |
| 风车 | 5/3/4 | +1 | 船速 +0.5 |

> `autoBuild: true` 时跳过图纸选择，自动建造（用于节奏优先的模式）。

**3. 淡水生存**
水壶每秒消耗 1.5。水壶见底后每 1.2 秒掉 1 心。海面会定期漂来淡水瓶（+34）。
水塔建筑可提升上限。

**4. 危险海域（金色圈）**
一个缓慢移动的圆形海域，标记为金色呼吸光环：

- 其中的垃圾是「极品」版本，**材料与分值 ×2**
- 至少 1 只鲨鱼在此巡逻
- 普通垃圾和鲨鱼都刷在区域外，所以安全区永远有货

**5. 鲨鱼行为**

| 状态 | 行为 |
| --- | --- |
| cruise | 巡游靠近，近距离侧向绕圈 |
| windup | **停住并显示红色预警圈**（0.58–0.7 秒），给玩家反应时间 |
| lunge | 沿预警方向 2.3–2.55 倍速扑咬（0.8–0.9 秒） |
| cool | 硬直 1.3–1.5 秒，之后 4.5–8 秒才会再次扑咬 |

- **普通鲨鱼**：基础款
- **锤头鲨**：进度过半后有 30% 概率出现，体积 ×1.12、速度 ×1.25、扑咬更快

**6. 其他机制**

- **连击**：5 秒内连续打捞，音调递增
- **救生圈**：掉血后刷新，+1 心
- **宝箱**：随机刷新，+3 分并给护盾
- **鲨鱼潮**：每 22 秒可能出现小规模增援，屏幕提示「鲨鱼潮！」
- **昼夜渐变**：天色随进度从正午转向黄昏
- **波浪与浮动**：海面顶点实时起伏，木筏随浪起伏与侧倾

### 胜负

| 结果 | 条件 |
| --- | --- |
| 🏝 漂流小镇落成 | 造齐 6 座建筑 |
| 小镇初具规模 | 时间耗尽时 ≥4 座建筑 |
| 木筏被鲨鱼撞散 | 心数归零 |
| 水喝完了 | 口渴归零后持续掉血致死 |
| 天黑了 | 时间耗尽时 <4 座建筑 |

### 微信适配要点（已解决）

1. **无 DOM 环境** — 微信小游戏不渲染 HTML。所有 HUD（血条、计分、计时、结算卡、图纸选择卡、虚拟摇杆）都改为 **Canvas 2D 绘制**，作为全屏纹理叠加在 WebGL 画布上。
2. **胶囊按钮避让** — 通过 `window.GAME.safeArea.bottom` 把右上角计时器下移，避免被微信胶囊遮挡。
3. **无彩色 emoji 字体** — Canvas 2D 在部分环境把 emoji 渲染成方块，因此 HUD 全部改用**纯中文文字**（木/塑/铁、镇/民、水）。
4. **WebGL 失败提示** — 直接画在 canvas 上，不再创建 DOM 节点。

### 代码结构（game.js）

| 段落 | 内容 |
| --- | --- |
| 1. RULES | 全部数值来自 `GAME.rules`，含默认值兜底 |
| 2. RENDERER | 初始化 WebGL 渲染器，失败时降级提示 |
| 3. HELPERS | 噪声、颜色、程序化贴图 |
| 4. SEA | 海域生成（沙洲）、水面网格 |
| 5. CHARACTERS | 程序化体素模型（木筏、鲨鱼、锤头鲨、7 种垃圾、6 座建筑） |
| 6. AUDIO | WebAudio 合成音效与背景音乐 |
| 7. HUD | Canvas 2D 绘制全部 UI（跨平台） |
| 8. GAME STATE | 状态、材料、建筑、淡水、危险海域 |
| 9. INPUT | 键盘 + 触屏 + 图纸选择 |
| 10. UPDATE | 主循环：移动、鲨鱼状态机、拾取、建造、口渴 |
| 11. CAMERA | 跟随镜头、震屏、结算视角 |
| 12. LOOP | requestAnimationFrame |
| 13. STATE | `__gameState` / `__autoplay` / `__renderSlots` |
